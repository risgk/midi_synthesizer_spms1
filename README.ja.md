SPMS-1 (type-0)
---------------

- Raspberry Pi Pico 2 用のモノフォニック MIDI シンセサイザー
- 必要なハードウェア: Raspberry Pi Pico 2、Pimoroni Pico Audio Pack (または代わりとなる I2S DAC ハードウェア)
- [README](./spms1_type0/README.ja.md)
