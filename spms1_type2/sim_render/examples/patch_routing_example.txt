; An example patch for sim_render and sim_cruby/spms1_render.rb, written as the editor copies one
; with Format "MIDI bytes (hex)": NRPN writes on MIDI channel 1, taken after the default patch.
; It rewires a few inputs of the default patch:
B0 63 01 B0 62 07 B0 06 22   ; NRPN 135 Mixer 1 In 1   <- Osc 1 (34)
B0 62 08 B0 06 16            ; NRPN 136 Mixer 1 In 2   <- EG 1 (22)
B0 62 20 B0 06 20            ; NRPN 160 Output L       <- Mixer 1 (32)
B0 62 18 B0 06 1A            ; NRPN 152 Filter 1 Mod 1 <- LFO 1 (26)
B0 63 02 B0 62 14 B0 06 01   ; NRPN 276 Mixer 1 Level 1 <- 1.0 (1)
B0 62 15 B0 06 01            ; NRPN 277 Mixer 1 Level 2 <- 1.0 (1)
B0 65 7F B0 64 7F            ; RPN null
