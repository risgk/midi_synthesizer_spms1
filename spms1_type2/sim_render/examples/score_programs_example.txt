; An example score of the programs: Save as program #3, a change, then Program Change back to it,
; and Clear.
; The time in seconds, then the MIDI bytes in hex; ';' starts a comment.
0.0   90 30 64                    ; Note On C3
0.5   B0 63 75 B0 62 00 B0 06 7F  ; Mute on (NRPN 117/0)
0.5   B0 62 04 B0 06 03           ; Program #3 (NRPN 117/4)
0.5   B0 4A 14                    ; CC 74 (Filter Cutoff) down
0.5   B0 62 02 B0 06 7F           ; Save (NRPN 117/2), as program #3
0.5   B0 62 00 B0 06 00           ; Mute off
1.0   B0 4A 7C                    ; CC 74 up again
1.5   C0 03                       ; Program Change #3: the cutoff down again, faded out and in
2.0   C0 05                       ; Program Change #5, not saved: no change
2.2   B0 4A 7C                    ; CC 74 up again
2.5   C0 03 C0 03                 ; Program Change #3 twice in a row: put back once
2.505 C0 03                       ; and once more, while silent
3.0   B0 63 75 B0 62 00 B0 06 7F  ; Mute on
3.0   B0 62 04 B0 06 03           ; Program #3
3.0   B0 62 05 B0 06 7F           ; Clear (NRPN 117/5): program #3 not kept
3.0   B0 62 00 B0 06 00           ; Mute off
3.2   B0 4A 7C                    ; CC 74 up again
3.5   C0 03                       ; Program Change #3, cleared: no change (the cutoff stays up)
4.0   80 30 40                    ; Note Off C3
